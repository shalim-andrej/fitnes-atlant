# Атлант — сайт фитнес-клуба

Одностраничный сайт фитнес-клуба: тренажёрный зал, кроссфит, бокс. Центральная конверсия — лид-магнит «первая тренировка — 0 ₽» и форма записи на пробное занятие.

**Демо:** [shalim-andrej.github.io/fitnes-atlant](https://shalim-andrej.github.io/fitnes-atlant/)

## О проекте

Концепт-сайт вымышленного клуба «Атлант» — портфолио-кейс для спортивной ниши. Главная задача такого сайта — снять страх «не получится»: направления показывают, чем можно заниматься, расписание — что подойдёт по времени, тренеры — с кем, тарифы — за сколько. Пробная тренировка бесплатно опускает порог входа до нуля.

Вёрстка написана с нуля, без конструкторов и фреймворков: чистые HTML, CSS и JavaScript.

## Структура страницы

| Блок | Задача |
|---|---|
| Первый экран | оффер «первая тренировка — 0 ₽» |
| Направления | тренажёрный зал, кроссфит, бокс |
| Расписание | занятия по дням и времени |
| Тренеры | команда и квалификация |
| Тарифы | карты и абонементы |
| Запись | форма на пробное занятие |

## Технологии

- **HTML5** — семантическая разметка, логичная иерархия заголовков
- **CSS3** — Flexbox и Grid, адаптив от смартфона до широкого монитора
- **JavaScript (vanilla)** — вся интерактивность без внешних библиотек
- **Форма записи** — заявка на пробную тренировку с минимальным числом полей
- **SEO-база** — `<title>` с направлениями и оффером, `meta description`

## Запуск локально

```bash
git clone https://github.com/shalim-andrej/fitnes-atlant.git
cd fitnes-atlant
```

Откройте `index.html` в браузере — сборка и зависимости не нужны.
